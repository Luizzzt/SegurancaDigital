# Segurança em Compras Online

Projeto de Extensão da Universidade Presbiteriana Mackenzie.

O objetivo do projeto é ajudar as pessoas a reconhecer e evitar golpes em compras online, como sites falsos, anúncios enganosos em redes sociais e mensagens falsas de entrega ou cobrança.

## Acesse

- **Desafio interativo "Ache o golpe":** https://luizzzt.github.io/SegurancaDigital/
- **Vídeo:** https://www.youtube.com/watch?v=mVvlddxGqFw

## O que tem no projeto

- **Pesquisa:** formulário com 34 respostas sobre os golpes que as pessoas mais sofrem.
- **Vídeo:** explica como os golpes acontecem e como se proteger.
- **Desafio:** três telas de celular (anúncio em rede social, site de loja e mensagem de entrega) para a pessoa encontrar os sinais de golpe. No final aparece a pontuação e dicas do que lembrar antes de comprar.

## Ferramentas

HTML, CSS e JavaScript, GitHub Pages, Google Forms e CapCut.
